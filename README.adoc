= Software for Robots

Source of https://ennerf.github.io, built with Jekyll, the
https://github.com/cotes2020/jekyll-theme-chirpy[Chirpy] theme (as a gem) and
https://github.com/asciidoctor/jekyll-asciidoc[jekyll-asciidoc].

* Posts are AsciiDoc files in `_posts/`, named `YYYY-MM-DD-Title-With-Dashes.adoc`. The file name becomes the URL, so never rename a published post.
* Unfinished posts live in `_wip/`. `runServer.bat` shows them under http://localhost:4000/drafts/; the deployed site does not contain them. To publish one, move it to `_posts/` with a `YYYY-MM-DD-` prefix.
* Images go into `images/`, referenced relative to that directory (`image::udp/setup.png[]`).
* Tags come from `:page-tags: a, b` in the post header; `_plugins/adoc-tags.rb` turns that String into the Array Chirpy and jekyll-archives expect.
* Sidebar tabs are in `_tabs/`, sidebar contact links and post share buttons in `_data/`.
* Style overrides go into `assets/css/jekyll-theme-chirpy.scss`, which also holds the AsciiDoc block styling and the MATLAB-editor syntax colors used in light mode.
* Every push to `master` is built and deployed by `.github/workflows/pages.yml`.

Local preview: `runServer.bat` (Docker), or with Ruby installed `bundle install` once, then `bundle exec jekyll serve --config _config.yml,_config.local.yml`; open http://localhost:4000.
